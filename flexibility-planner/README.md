# Flexibility Planner

Pick a flexibility skill, rate yourself on a few quick tests, and get the
stretches you need, in order, with doses, a weekly schedule and a target date.

Covers the eight skills from Matt Smith's *The Blueprint to Get Flexible
Once, Forever* (pike, pancake, side split, front split, bridge, overhead
shoulder, shoulder extension, deep squat), with a 73-exercise catalog. Every
exercise has a demo video.

## Use

Open `index.html` in a browser, or host the folder anywhere static
(GitHub Pages works as-is). No build step, no dependencies.

Answers and the test log are saved in the browser on that device only. Use
Export / Back up in the Test log to keep a copy.

## Take it with you

- **Phone image:** each plan makes a 1080 x 1920 card with the stack, the
  week and the next retest date, ready to save to your photos.
- **Print:** a one-page plan with a blank retest sheet for the next three
  retests.

## Files

- `index.html` – the page
- `data.js` – skills, self-tests, methods and the exercise catalog
- `app.js` – plan generator, scheduler, catalog and progress log
- `style.css` – styles
- `fonts/` – EB Garamond (SIL Open Font License, see `OFL-EBGaramond.txt`)
