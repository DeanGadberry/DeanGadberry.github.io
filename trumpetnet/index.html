Trumpet Net

Version 15

In what place therefore ye hear the sound of the trumpet, resort ye thither unto us: our God shall fight for us. Nehemiah 4:20

Trumpet Net is our group's emergency radio plan. Every radio we program carries the same channel list, so a channel number means the same thing on every radio. This page has the handout, the channel file for programming radios, and a map of the repeaters on the list.

The handout

A two-sided, letter-size trifold that goes with every radio: how to talk on the air, the phonetic alphabet, a page to plan each operation, and every channel on the list.

Print both sides (flip on the long edge), then fold in thirds so the title is on the front.

Program a radio

The full channel list as a file for CHIRP, the free radio programming program.

  1. Plug the radio into your computer with a programming cable and turn it on.
  2. In CHIRP, choose Radio → Download from radio.
  3. Choose File → Import and pick this file.
  4. Choose Radio → Upload to radio.

Check your radio

Turn to channel 0. It should read VER 15. If your radio has no channel 0, use channel 108. A different number means the radio has an older list and should be reprogrammed.

How versions work: the whole number changes only when channels change, so it always matches your radio. A decimal on the handout (15.1, 15.2…) means only the paper was revised.

Licenses: the file lets every channel transmit. Ham channels need an amateur license and GMRS channels a GMRS license. FRS channels 1–22 need none. Anyone may use any channel when a life is in danger.

    How the channels are numbered

    The tens digit tells you the region. Every region's main emergency repeater ends in 0, and its talkaround ends in 9. Start on the channel ending in 0, then try the other ★ county primaries in that block. Simplex and GMRS channels work with no repeater at all.
